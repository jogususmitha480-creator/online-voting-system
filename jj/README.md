# Online Voting System in Java

## Project Description

This project is a console-based **Online Voting System** developed in **Java**. It allows registered voters to log in, cast a vote for a candidate, and prevents duplicate voting. The system stores voter information and votes using text files.

## Features

* Secure voter login
* View candidate list
* Cast vote once
* Prevent duplicate voting
* Store votes using file handling
* Display election results

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* File Handling
* Console-based UI

## Project Structure

* `src/` – Java source files
* `data/` – voter and vote data
* `screenshots/` – output screenshots
* `output/` – sample execution output

## How to Run

1. Open the project in VS Code, IntelliJ IDEA, or Eclipse.
2. Compile all Java files.
3. Run `Main.java`.
